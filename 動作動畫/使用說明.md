# 新版人物動作動畫

- 雙擊「精緻動作圖庫.html」：可離線搜尋、逐個播放／暫停、下載 GIF、查看依據。
- `gif/`：68 個 640×640 循環動畫；標示安全提示、視角與慢速示範。
- `svg/`：68 個可在瀏覽器播放的向量版本。
- `poster/`：68 個靜態封面，供圖庫暫停及省流量使用。
- `原版動畫備份.zip`：修改前的全部 GIF／SVG。

單邊動作部分僅示範一側；另一側鏡像執行，次數／秒數依 APP 標示。箭頭是方向示意，不是必須做到的幅度。APP 內亦已改成人物插畫；GIF 與 APP 使用同一份關節原稿。

這是 2D 教學插畫，並非動作捕捉，未經物理治療師逐格審核。請同時閱讀「../運動安全查核.md」；不適加重、放射痛、麻刺或無力時停止。不能憑 GIF 保證個人適用或保證矯正體態。

重新產出：執行 `../dev/export_animations.bat`，需要 Node.js + sharp、Python + Pillow；會優先使用本機已有的 Codex 套件，沒有呼叫付費 AI 或外部圖像 API。
