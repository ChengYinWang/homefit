# 每日居家運動 APP

線上版：https://chengyinwang.github.io/homefit/ （iPhone 用 Safari 打開 →「分享」→「加入主畫面」）

自己用的居家徒手運動網頁 APP（PWA），可以加入 iPhone 主畫面，用起來就像一般的 APP。

## 功能

- **規則式教練**：依身高、體重、體能程度、目標和不舒服的部位，從 60 多個徒手動作中排出每日課表（暖身 → 主訓練數輪 → 伸展），並每天輪替訓練重點。
- **改善體態目標**（骨盆前傾／駝背／久坐腰痛）：
  - 核心控制（死蟲式、鳥狗式、骨盆小幅活動、側棒式）、臀部（雙腳臀橋、髖鉸鏈）、上背（Y-T 舉、靠牆天使）依耐受選課。
  - 暖身優先原地踏步、收下巴；伸展依膝肩等不適篩選。
  - 骨盆角度不等於腰痛診斷。不能保證矯正或治癒；詳見 [68 動作證據與安全查核](運動安全查核.md)。
- **動作動畫示範**：68 個運動服人物插畫，APP 即時播放；另附 [離線圖庫](動作動畫/精緻動作圖庫.html)、640×640 GIF／SVG 與原檔 ZIP 備份。
- **運動播放器**：動畫示範、計時倒數、嗶聲、語音報動作名稱、休息計時、動作要領；運動時螢幕不會自動關閉。
- **連勝**：🔥 連勝天數、每週打卡、徽章（3／7／14／30／60／100／180／365 天）。每連續 7 天送 1 個 🧊 連勝凍結（最多 2 個），哪天沒運動會自動用掉，保住連勝。
- **熱量**：依 MET 公式估算每次運動的消耗，另外顯示基礎代謝與全天估計消耗。
- **運動後回饋**：記錄強度（1–10）、心情、痠痛部位和做不完的動作，自動調整下次的課表：
  - 覺得輕鬆 → 增加次數或秒數，累積到一定程度就升級成進階動作
  - 覺得很累 → 降低強度
  - 有痠痛 → 隔天避開那個部位
  - 有動作做不完 → 換成較簡單的版本
- **資料**：只存在手機裡，可以匯出／匯入備份。

## 在電腦上試用

在這個資料夾執行：

```bash
python dev/server.py
```

然後用瀏覽器打開 http://localhost:8123 。按 F12 開啟手機模擬模式，看起來會更接近手機上的樣子。

## 檔案結構

| 檔案 | 用途 |
|---|---|
| `index.html` | 頁面入口 |
| `css/style.css` | 外觀（支援深色模式） |
| `js/exercises.js` | 動作庫：可以在這裡新增或修改動作 |
| `js/planner.js` | 課表產生與依回饋調整的規則 |
| `js/streak.js` | 連勝、凍結、徽章、基礎代謝 |
| `js/store.js` | 本機資料儲存 |
| `js/app.js` | 畫面與運動播放器 |
| `js/figure.js` | 運動服人物插畫動畫（每個動作的關鍵姿勢） |
| `js/safety.js` | 68 動作的來源、限制與安全提示 |
| `dev/gallery.html` | 開發用：一次預覽所有動作動畫（http://localhost:8123/dev/gallery.html） |
| `sw.js` | 離線快取：**每次修改程式後，把裡面的 `VERSION` 改成新的值**，手機才會抓到新版 |
